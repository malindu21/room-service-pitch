# Room Service Ordering — pitch page

Static one-page pitch for the in-room food ordering app. No build step:
`index.html` plus images and the PDF.

## Publish with GitHub Pages

1. Push this folder's contents to the root of the repo's `main` branch.
2. Repo **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   branch `main`, folder `/ (root)`.
3. The page is live at `https://<user>.github.io/<repo>/`.
